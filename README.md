# PPH Outpatient Rx

Pangasinan Provincial Hospital Prescription and Follow-up Scheduler, personalized for Francis Gerald Lopez, MD.

Open [the app](https://poginuxx.github.io/pph-rx/) or download `PPH_Prescription_Followup.html` and open it in a browser for offline use.

Enter patient details and medications, select an optional follow-up, and print the hospital prescription pad. Longer prescriptions continue on additional complete sheets.

Medication catalog additions and preferences are stored in the browser. Use **Manage medication catalog → Export my catalog** to transfer additions from the local app to the hosted app. Patient details, prescriptions and follow-up dates are not saved by the app.

The site is served directly from the `main` branch with GitHub Pages. The standalone HTML file contains all CSS, JavaScript and images.
