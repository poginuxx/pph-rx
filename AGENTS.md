# Francis's app design preferences

Use the PPH Prescription and Follow-up Scheduler in this workspace as Francis's reference for a clean, minimal interface. Carry these preferences into future app work when they fit the task.

- Keep the most frequently used fields in a compact bar that stays visible while scrolling. Put secondary fields behind a clearly labeled disclosure.
- Arrange controls where the user needs them. In the prescription app, Sig sits below the medication name, quantity shortcuts stay beside it, and “Add medication” follows the last row.
- Keep layouts stable as options appear. Use short, recognizable shortcuts, support keyboard selection, and leave the resulting values editable.
- Make the result visible as the user works. The calendar updates the prescription preview directly when a day is selected.
- Keep labels and status messages that help the user act. Omit filler text, repeated instructions, and storage or booking controls when the task only needs printed output.
- Prefer restrained colors, legible type, and consistent spacing. Keep the primary action easy to find on both desktop and phone screens.
